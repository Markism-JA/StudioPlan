## How the Team Uses This

1. **Before Discovery Calls:** Review Section 2 (*Architecture Configurator*) and Section 3 (*Modular Add-Ons*) of [OFFER_CATALOG.md](./OFFER_CATALOG.md) so everyone quotes the exact same scope, timelines, and add-on prices.
2. **During Discovery Calls:** Walk the prospect through the 3 architecture choices (Frontend Pattern, Backend Engine, Cloud Target) to lock Package A, B, or C + any add-ons.
3. **After Signing:** Freeze the agreed scope in the SOW and run the 30-day sprint calendar (Week 1 Setup → Week 2 Core Build → Week 3 QA/Polish → Week 4 Final Payment & OpenTofu Production Handover).
